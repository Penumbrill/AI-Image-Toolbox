# AI Image Editing Tools

[English](README.en.md) | [简体中文](README.md)

Windows / Android 本地图像工具箱。提供双图切换、背景显图、像素混淆、文件封装、GIF、元数据清理、打码、生成参数读取和二维码制作。无需注册，图像处理不上传文件。

## 安装与开始使用

Windows：下载 [EXE](releases/Windows/AI-Image-Editing-Tools.exe) 后运行。Android：下载并安装 [APK](releases/Android/AI-Image-Editing-Tools.apk)，按系统提示授予文件或相机权限。iOS 不支持此 APK，可用系统相机扫描生成的网址二维码。

从左侧工具集合选择功能；手机点击菜单按钮打开可滚动工具列表。先导入图片或文件、检查预览，再选择输出位置并导出。各功能自动建立子文件夹，输入文件保持不变，重名输出使用新名称。软件中的设置下方有同内容的“使用教程”，支持目录跳转与离线查询。 两端功能与平台差异见 [Windows / Android 功能对照](docs/PLATFORM_PARITY.md)。

## 1. 双图切换

将封面和另一张图片保存为动态 PNG。静态预览显示封面，支持动画的查看器显示内层图片。是否在点开或查看原图后切换，由平台如何处理动画决定。

### 操作步骤

1. 批量导入要放在内层的图片，选择队列中的一项，检查封面和内层预览。调整队列顺序会改变导出顺序与编号。
2. 使用自动封面，或选择自己的封面。可以为每张图片单独选封面，也可以将当前封面应用到其他项目。
3. 按需添加多条封面文字。选择文字图层后修改内容、字号、颜色和位置；自由拖动或输入横向、纵向百分比，每条可单独删除。
4. 设置编号与导出尺寸，导出当前图片或整个队列。将生成的 PNG 作为原图发送，先在目标平台实际测试。
5. 还原时，在页面下方导入生成文件，查看两张图，并导出封面或内层图片；也支持识别背景显图文件。

### 主要选项与使用细节

- 文字字号按图片短边计算，位置按画布百分比计算。图层名称显示当前文字，长内容缩略显示；切换图层不会删除其他文字。
- 最长边可选 1200、2048、3200 像素或原尺寸。封面会适配画布，内层图可能缩放；“原尺寸”对大图占用更多内存。
- 编号可关闭。先调好当前项目，再应用封面设置；批量导出以队列实际配对为准。
- 可勾选任意队列子集、全选或取消；批量导出优先处理勾选项，未勾选则使用全部。“移除”优先移除勾选项，没有勾选时处理当前行。导出顺序仍按队列及实际封面配对。

### 输出、还原与兼容性

输出位于“双图切换”子文件夹。还原得到文件中保存的图像，不能恢复被缩放前的像素、原始编码或已删除的动画帧。平台转成静态图、截图或重新编码后，可能失去切换与还原能力；这不是加密。

## 2. 背景显图

生成透明 PNG，在白底与黑底上显示不同内容。这个页面不自动添加封面文字或编号；输入图片中已有的文字仍属于图片像素。

### 操作步骤

1. 导入黑底显示的图片，选择彩色叠显或黑白叠显。默认按原图尺寸和配色生成无文字封面，也可选择自己的白底封面。
2. 选择处理方式，阅读下方随选项变化的说明。白底与黑底预览展示实际透明合成结果。
3. 调整色彩强度和导出尺寸，刷新效果预览。原色优化支持自定义有效色彩强度，也可恢复自动调节。
4. 确认两侧预览后导出当前项或批量导出。还原按钮或双图切换中的还原区可提取白底、黑底显示图。

### 主要选项与使用细节

- 均衡色彩：使用基础彩色叠显；原图优先：优先照顾黑底画面；原色优化：自动收紧色域、保留区域配色并弱化细碎颜色。
- 轮廓优先使用统一色调，只有该处理方式显示固定颜色封面选项；彩色自动封面可选择按原图配色或自选图片。黑白模式不使用彩色封面。
- 二维码优化用于本工具生成、保留联动信息的二维码 PNG：白底显示封面，黑底显示二维码，导出会检查识别结果。
- 请求色彩强度与有效色彩强度不同：透明合成可表达的颜色有限。提高有效强度可保留更多颜色，也可能让封面露出更多原图信息。

### 输出、还原与兼容性

输出位于“背景显图”子文件夹，保留透明 PNG。提取的是调节后的显示画面，不是原文件字节。QQ、相册、资源管理器可能使用灰底、棋盘底或不同合成方式；软件中的白黑预览不能保证所有查看器均无互透。

## 3. 图片混淆

按确定的像素排列规则混淆图片，再按逆向规则还原。可选择保留原文件的模式或只处理像素的模式。

### 操作步骤

1. 导入图片并选择队列项，查看混淆前后预览。
2. 选择生成质量；压缩 JPG 可调质量，预览显示生成结果和编码后的文件大小。
3. 混淆当前项或批量混淆，保存生成文件。
4. 还原时导入混淆图。像素还原执行逆排列；原文件还原从支持的文件中提取原始内容。

### 主要选项与使用细节

- 原图质量（可还原原文件）：输出 PNG 并附带原文件内容，可还原文件字节；文件会较大。
- 无损 PNG（仅像素）：保留排列后的像素，逆排列可恢复像素，但不等于恢复原始编码、元数据。
- 压缩 JPG：可减小文件，但有损压缩造成的像素变化无法通过逆排列消除。还原输出的压缩质量可单独设置。
- 批量操作按队列顺序处理。动画图的像素处理使用首帧；原文件模式保留的原始文件可以包含完整动画。

### 输出、还原与兼容性

输出位于“图片混淆”子文件夹。缩放、截图、打码、网站重编码会影响像素还原，也可能破坏附带的原文件。该功能用于混淆展示，不提供密码加密。

<a id="disguise"></a>
## 4. 文件伪装

将视频或压缩包与封面组合成 JPG/PNG 外观文件，之后提取原文件。这里不转码视频，也不重新压缩原始压缩包。

### 操作步骤

1. 在视频或压缩包区域导入文件，按需调整队列顺序。选择封面，可使用共享封面或项目独立封面。
2. 设置封面文字、字号、颜色和位置。支持多条文字，每条独立拖动、定位与删除；编号按队列生成。
3. 选择封装方式和封面尺寸，导出当前项目或全部项目。
4. 在还原区域导入生成文件，自动识别封装并提取视频或压缩包。若需要验证传输，使用发送文件和接收原文件的对比功能。

### 主要选项与使用细节

- JPG 封装保存原文件信息并校验还原；copy/b 拼接方式使用直接拼接，没有同等的原文件信息记录。
- PNG 内嵌 ZIP 将原文件原样放入 ZIP；PNG IDAT 内嵌 ZIP 是兼容性更受限制的实验方式。
- PNG ZIP 方式可复制生成文件、将副本扩展名改成 .zip 后解压，得到的条目仍是原来的 MP4、RAR 等文件。本工具直接还原更方便。
- 仅改变 JPG 扩展名不能保证视频播放器能够播放。第三方提取工具对拼接文件的支持不同。
- Android 封面保留源图比例，不为封装自动裁切；默认最长边 1600 像素，另可选 1200、2048 或原尺寸。为使封面适合 512 KiB 预算，软件可能继续等比缩小；未选择封面时自动封面为 800×500。输出封面仍需实际查看。
- Android 提供 QQ 手工往返验证：选择发送前的封装文件与收到后保存的同一封装文件，不先提取；比较实际字节数和 SHA-256，并按页面要求确认客户端与发送渠道，导出本次报告。报告只记录这次真实文件比较与用户确认，不代表所有 QQ 版本、渠道或文件均可传输。

### 输出、还原与兼容性

输出位于“文件伪装”子文件夹。发送时保留原文件；网站或聊天软件重编码图片后，附带数据可能丢失。校验仅证明本次比较的文件一致，不代表所有客户端均兼容。封装不等于加密。

## 5. 合成 GIF

将多张静态图片按队列顺序合成为动画 GIF，并可在导出前播放预览。

### 操作步骤

1. 导入至少两张图片，按播放顺序上移、下移或移除项目。
2. 设置每帧间隔、最长边尺寸与是否循环播放。Android 间隔为 20–10000 毫秒、最长边为 100–2048 像素。
3. 点击播放逐帧预览，检查顺序、速度和边缘填充；可点击停止。Android 切换页面或窗口隐藏时停止播放，确认后导出 GIF。

### 主要选项与使用细节

- 帧间隔越短播放越快。尺寸越大，文件大小与内存占用通常越高。
- 画布按第一张图的比例建立，其他图片居中适配；边缘填充颜色在设置中调整。
- GIF 使用有限调色板，颜色和渐变可能变化。动画输入按首帧作为一张图片使用。
- 队列勾选项决定要合成的图片；未勾选时使用全部。参与合成的图片至少两张，顺序仍按队列排列。

### 输出、还原与兼容性

输出位于“合成GIF”子文件夹。GIF 不是原始输入文件的容器，不能从中恢复源图片的编码、元数据或缩放前细节。

<a id="clean"></a>
## 6. 清信息

清除图片中的生成提示词、工作流及部分拍摄信息，尽量保留图像编码数据、色彩信息和动画结构。支持 PNG/APNG、JPG、WebP、GIF。

### 操作步骤

1. 导入需要清理的图片，选择单项或批量处理。
2. 如需保存生成参数，先用 tag读取查看并导出 TXT。
3. 执行清理，将新文件保存到输出目录，检查图片显示和动画。

### 主要选项与使用细节

- 本功能不重新绘制图片，也不在原文件上覆盖保存。颜色描述和显示方向等必要信息可能保留。
- 某些格式可清理但当前系统不支持预览，这不代表无法处理。
- 含原文件附件、二维码联动等特殊数据的图片应保留未清理副本；清理可能移除还原或联动所需的信息。

### 输出、还原与兼容性

输出位于“清信息”子文件夹，尽量保持原格式。已清除的提示词、工作流等无法从清理后的文件重新恢复，原文件仍保留。

## 7. 打码

用矩形或画笔选区为图片应用马赛克、模糊或纯色覆盖，支持撤回、重做和恢复原图。

### 操作步骤

1. 选择图片，选择矩形或画笔工具，在预览上绘制要处理的区域。
2. 选择效果，调整强度、画笔直径或填充颜色，点击应用。
3. 撤回恢复上一个编辑状态，重做恢复刚撤回的修改。清除选区只清除尚未应用的选择；恢复原图移除已应用的修改。
4. 检查结果，保存 PNG。

### 主要选项与使用细节

- Windows 可用滚轮缩放、中键平移；画笔大小可用界面调整。手机支持触摸绘制与缩放，滚动页面后短暂暂停绘制，减少误操作。
- 历史最多保存 50 步，并受内存预算限制，大图可用步数可能减少；撤回后新增修改会清空重做历史。
- 纯色覆盖直接替换选区像素；模糊与马赛克保留一定结构。文字、二维码等需保持可识别的区域不要打码。
- Android 纯色覆盖可使用颜色预设或任意 RGBA / HEX 值；确认颜色后再应用，源图与完整画布仍保留在编辑会话。

### 输出、还原与兼容性

输出位于“打码”子文件夹，保存完整画布的静态 PNG，输入动画仅编辑首帧。未覆盖原文件；关闭会话后不能从打码结果中还原已替换的原始像素。

## 8. tag读取

读取图片中已有的 Stable Diffusion WebUI / ComfyUI 生成参数。这里不会根据画面自动猜测提示词。

### 操作步骤

1. 导入包含生成信息的 PNG/APNG、JPG 或 WebP。
2. 查看 WebUI 和 ComfyUI 分栏；可一次从同一张图片读取两栏，也可分别导入不同图片。Android 提供“同时读取两栏”和“复制全部参数”。
3. 查看正向、反向提示词及模型、种子、采样器、步数等实际存在的参数。
4. 使用单字段复制、复制全部或导出 TXT 保存需要的信息。

### 主要选项与使用细节

- 不支持的自定义工作流节点可能只能显示部分参数；结果以文件实际保存的信息为准。
- 没有数据的字段不会凭空补全；清理过元数据、截图或网站转码的图片可能没有生成信息。
- 文本只读不改变输入图片。两栏 TXT 独立输出，未加载或没有信息的栏不生成空文件。

### 输出、还原与兼容性

TXT 输出位于“tag读取”子文件夹，名称避免覆盖已有文件。该功能不下载模型、不生成图片，也不能恢复已删除的参数。

## 9. 二维码制作

将网站链接、文本或名片内容编码为通用标准二维码，也可从 QQ、微信等二维码截图提取内容，再单独融合进底图。支持标准二维码的系统相机与扫码器可读取；具体内容的打开方式由扫码应用决定。图片、识别和推理保留在本机，不上传。

### 操作步骤

1. 输入完整网址或粘贴内容；也可点击“导入二维码图片”（Android 为“导入截图中的二维码”），从截图识别二维码。多码时先选择需要的一项；导入后保留原始内容，不带入昵称、头像和截图界面。
2. 选择生成方式：直接生成、图片附上二维码、像素纹理融合，或本地 AI 内嵌二维码。图片模式先选择底图，内容不限衣服、人物或风景。Windows 可点击页面最上方空白预览中的“点击选择图片”，也可把图片拖到此预览框作为底图；Android 可点击空白“二维码预览”选择底图，或使用“选择底图”按钮。QQ、微信等截图的内容提取请使用导入二维码按钮。
3. 调整大小、横纵位置，选择拖动二维码或当前文字。Android 长按预览拖动；多条文字可分别设置、定位与删除。普通和像素模式可调白边，AI 模式不附加白色边框。两端 AI 默认“手动放置（位置由你指定）”，可用普通二维码示意调位置；也可选择“自动避开皮肤与头发放置”。这两个定位选项最多勾选一个，也可都关闭。“自动识别画面并生成提示词”始终单独显示；取消勾选即可编辑手动提示词，手动放置也可使用自动提示词。生成成功后显示实际融合结果；修改放置模式或位置后需重新生成。
4. 本地 AI：选择底图、确定二维码区域，点击一键 AI 生成。Windows 首次自动准备私有 Python、依赖、基础模型、二维码 ControlNet、画面描述与人物保护模型；Android 生图与识图运行库已在 APK 内，首次仅准备所缺模型。模型准备完成后，两端均在设备本地识别画面、生成提示词并推理，无需连接电脑或 ComfyUI。
5. 两端 AI 会逐次调整约束并校验完整图及缩小图的实际解码内容。通过后可导出；全部重试失败会提示失败，不把不能扫描的图当成功结果。图片生成完毕后可添加文字。添加文字后导出再次检查，请用目标手机与传输平台复测。Windows 内嵌二维码结果显示在页面最上方的预览框；可点击“查看顶部预览”返回查看。Android 结果显示在本页“二维码预览”框，导出前请先查看。
6. 导入图片或启动相机扫描，核对结果，点击复制或打开网站。透明 PNG 自动尝试白底与黑底识别。

### 主要选项与使用细节

- 普通模式白边可调 0–12 格，推荐至少 4 格；像素纹理融合至少保留 4 格，保留识别核心，速度较快、无需模型和联网，但不能生成新的场景。Windows 和 Android 均保留像素策略。带底图的模式保留完整图片并等比适配；AI 使用适合模型的工作画布，融合结果回到完整底图；不按二维码方形裁切导出原图。
- “清空预览”位于导入二维码按钮旁。Windows 清除当前底图、普通二维码示意和 AI 生成结果；Android 清除当前底图、二维码预览及 AI 结果。清空后可点击空预览重新选择底图，Windows 也可拖入图片。二维码内容、模型选择和文字设置保留，源图片文件不被删除；之后重新选择底图并生成即可。

- Windows AI 的自动识图提供共用的底图和局部材质信息，最终提示词采用当前模型方案。DreamShaper 8 与 SDXL Base 1.0 有各自内置方案；其他本地模型默认采用对应家族方案，不能保证所有模型都适合相同自然语言描述。需要专用标签或触发词时，在“模型与环境方案…”中选中模型并开启“为选中模型自定义自动提示词与参数”，按模型说明保存正向 {prompt}、负向 {negative} 模板和生成设置；这些占位符保留底图识别信息。0 使用自动参数；可设置步数 8–60、CFG 1–12、强度 0.15–0.85，SD 1.5 的 CLIP skip 为 0–2；皮肤强度仍不超过 0.28。关闭自定义恢复内置方案。切换会同步加载该模型配置并要求重新生成。普通 Canny / Depth ControlNet 不能代替二维码模型；SD2、FLUX、SD3、Refiner、Inpaint、Turbo、Lightning、LCM 等不在此默认流程支持范围，架构校验与扫码成功也不等于所有图片自然度已验证。

- Windows 私有环境不会修改系统 PATH，无需安装 WebUI。检查并修复按钮修复本工具环境，不会修复显卡硬件或代替显卡驱动升级。无可用 CUDA 时使用较慢的 CPU。

- 两端 AI 的自动提示词只从整图和二维码区域的描述中提取风格与材质语义，引导沿用原有插画或照片风格、织物、建筑、植物等材质，忽略描述模型猜测的人物动作、身份与道具；未知或不可靠的配色沿用原图，不根据头发、帽子等猜测改变衣服颜色。局部材质提示词避免要求新增人物、脸或肢体。“自动识别画面并生成提示词”与二维码位置选择独立：勾选时使用自动提示词，取消勾选后可编辑手动提示词，无需关闭手动放置。默认开启自动识图；选择手动位置不会隐藏这个独立开关。切换位置选项不替你取消自动识图，自动避让的放置逻辑保持。修改二维码内容、底图、位置、提示词、模型或生成参数后需要重新生成；改变文字无需重新加载模型。
- Windows AI 默认保留原背景，空白背景补景需手动开启。局部衣物提示词沿用原有颜色、织纹、款式、轮廓与褶皱；融合使用原图色调与平滑边缘。Windows AI 还会尝试恢复已修改衣物区域的原图细小织纹，通过扫码校验才采用；失败则继续校验恢复前的候选，该织纹恢复操作不改变衣物外和未修改衣物的候选像素。检测到的人脸、眼镜、头发及已有马赛克设为保护区，保留源图像素。手动选择的肢体皮肤码区（如手臂、颈部和腿部）可沿用原肤色进行有界明暗融合，仍需通过保护与扫码校验。检测可能遗漏或误判，尤其是小人物、插画、细发丝与不规则打码，请逐一检查预览。
- 融合保留通用扫码器所需的定位信息。Windows 兼容 CUDA 的 SD 1.5 高显存材质路径尝试局部潜变量修整，将连续定位方框改为原图颜色的中心与周围小点，再尝试恢复点后原图纹理，仅调整必要的局部明暗；通过扫码才采用此变体。若失败则保留上一版并继续校验。仍保留三组定位信息，识别纹理可能可见，没有全圆形或无定位结构模式。自然纹理与扫码可靠性存在取舍，不能保证任意图片达到参考案例效果。Android 采用原生 CPU 扩散，以原图纹理和圆形中心点/周围小点引导生成；不添加白色或模糊底板，定位点后方保留原图。手动放置的自动提示词根据所选区域的材质生成，避免把人物衣物描述套到背景建筑或树木上，自动避让的提示词逻辑保持不变。生成纹理映射回原图配色，扫码失败时仅校准必要点位的明暗；完整图与缩小图均通过才采用结果，仍失败则报告失败。Android 不包含 Windows CUDA 潜变量修整路径，圆形点状定位仍可能可见。Windows CPU 较慢，其他显卡没有专用推理后端。

- Android 模型默认位于可用应用存储的 AI-Models 子目录，优先使用空间足够的外部应用存储，也可在“模型与环境方案…”选择列出的可用存储位置；手机没有 Windows 的 D、E 盘规则。界面显示真实目录和所选模型路径，“打开模型目录”显示应用内实际文件、大小及未完成分片，可复制路径。重新扫描在这些受管位置复用已校验文件，导入已有模型会做完整性与内容指纹检查；模型不会因切换方案重新复制。卸载 APK 可能同时清除应用专用模型目录，请按 Android 系统存储规则管理备份。

### 输出、还原与兼容性

输出位于“二维码制作”子文件夹，AI 输出 PNG。二维码包含选定的链接、文本或名片内容，不包含原图文件；网站访问仍需网络与目标网站权限。模型具有各自许可；人体分区模型沿用 NVIDIA SegFormer 的非商业许可，商业使用须另行核对授权。Windows AI 使用两套本地解码器，在原图与缩图上逐字核对完整内容。扫码自检只证明本机指定尺度能解码，不能保证所有手机、系统相机与压缩版本成功。内容不会自动打开。

## 10. 设置

### 操作步骤

1. 选择中文或 English，菜单、按钮和教程随语言切换。文件路径、文件名和原有生成参数不翻译。

3. Windows 和 Android 均可设置双图编号、默认导出尺寸与 GIF 默认间隔、尺寸、循环。Android 保存的默认值在下次启动时应用；当前队列不是永久项目。

### 主要选项与使用细节

- 功能切换保留当前会话中的队列和设置，但输入队列不是永久项目；关闭应用前保存需要的输出。
- 大图优先使用适当的最长边限制。批处理顺序执行，运行中可停止，已完成文件保留。
- 作者与项目链接用于查看项目；本机图像处理不依赖这些链接。手机 APK 是 Android 客户端，iOS 可用系统扫码访问二维码网站，但不是安装此 APK。
- 队列支持勾选任意项目、全选及取消全选。批量操作或全部导出优先处理勾选项，未勾选时处理全部；导出当前仍按当前行。“移除”优先移除勾选项，没有勾选时移除当前行。双图、文件伪装等使用每项实际封面配对；勾选不会改变队列顺序。
- Android 的边缘填充、文字和打码纯色支持颜色预设与手动 RGBA / HEX 输入，检查颜色预览后确认。颜色会影响画布适配与实际输出；纯色打码直接替换选区像素。

### 输出、还原与兼容性
