## 图像工具与公共操作

| 功能 | Windows EXE | Android APK |
| --- | --- | --- |
| 双图切换与还原 | 动态 PNG、封面配对、多条文字、编号、批量导出与还原 | 相同用途及处理入口；手机通过系统文件选择器导入 |
| 背景显图 | 黑白/彩色、五种处理方式、自定义有效强度、白黑预览、二维码联动 | 相同用途及选项；透明图的第三方显示仍需复测 |
| 图片混淆与还原 | 原文件附件、无损像素、JPG；批量及实际文件大小 | 同三种模式；默认手机工作画布 1200 像素，可选 2048 或原尺寸；原文件模式仍保存完整文件字节 |
| 文件伪装 | JPG、copy/b、PNG ZIP、IDAT ZIP，视频/压缩包还原 | 同四种封装及还原；自选封面保持比例，默认最长边 1600，可选 1200/2048/原尺寸并按封面预算缩小 |
| QQ 手工往返报告 | 选择发送及接收文件、核对大小/哈希、填写渠道并导出报告 | 同用途的实际文件比较和报告；不能据此推断未经测试的 QQ 传输方式 |
| GIF | 队列、间隔、尺寸、循环、播放/停止预览 | 同选项；间隔 20–10000 毫秒，最长边 100–2048 像素，隐藏页面停止播放 |
| 清信息 | PNG/APNG/JPG/WebP/GIF 元信息清理与批量处理 | 同格式处理入口；保留源文件，输出新文件 |
| 打码 | 矩形/画笔、马赛克/模糊/纯色、任意颜色、撤销/重做 | 同用途；触摸缩放/平移，滚动后暂停涂抹；可选工作尺寸，输出完整工作画布 |
| 参数读取 | WebUI/ComfyUI 分栏、同图两栏读取、逐字段/全部复制、TXT | 相同操作入口；读取文件实际元信息，不是识图生图 |
| 队列与批量 | 当前行、任意子集、全选/取消、排序、移除/清空 | 勾选任意子集；批量优先处理勾选项，否则使用全部；导出当前按当前行 |

| 空预览导入 | 点击选择或桌面文件拖入 | 点击空预览调用真实系统选择器；桌面拖放由触摸选图替代 |

## 二维码、离线 AI 与模型管理

| 功能 | Windows EXE | Android APK |
| --- | --- | --- |
| 普通二维码/截图导入/相机扫码 | 通用 QR、QQ/微信截图内容提取、多码选择、白黑底扫描 | 相同用途；只导入解码内容，不带昵称/头像；专有码不能伪装为通用 QR |
| 图片附码与像素纹理融合 | 大小/横纵位置、普通码定位预览、拖动 | 同位置设置、长按拖动、完整底图输出；像素模式无需模型 |
| 本地 AI 内嵌二维码 | 本机 Python/PyTorch/Diffusers，匹配二维码 ControlNet | 原生 CPU 扩散与 ONNX 识图，真正离线运行，无电脑转发 |
| 手动/自动位置 | 手动优先使用所选坐标；可主动自动避让或失败后选择自动避让重试 | 相同选择逻辑；两个定位选项最多一个，也可都关闭；自动位置隐藏普通码示意及位置控件 |
| 自动提示词与手动编辑 | 自动识图开关独立；关闭即可手动编辑，手动放置也可自动提示词 | 相同逻辑；BLIP、材质分区与人脸模型在设备本地推理 |
| 模型与参数方案 | SD 1.5 默认、SDXL/自选模型备用；按模型保存提示词模板与参数 | SD 1.5 默认、SDXL 高内存实验备用；同家族完整 safetensors/GGUF，按模型保存模板与参数 |
| 扫码验证与重试 | 原图/缩图精确内容验证；可用显存充足的 CUDA 修整路径 | 原生候选验证及局部亮度校准后再次精确验证；没有桌面 CUDA 高显存修整路径 |
| 完整图片、预览与文字 | 保留完整原图构图；生成后显示结果，可添加文字；文字后再次验证导出 | 相同流程；原生工作图局部融合回完整源图，人物保护区域保留源像素 |
| 下载来源 | 自动探测官方/镜像及响应时间，系统大陆地区优先可达镜像 | 自动探测官方/镜像，参考系统/运营商国家信息；只下载当前所选方案 |
| 后台下载与进度 | 文件数、总体字节进度、文件大小、速度、校验状态，可使用其他工具 | 同信息；独立后台任务及用户启动的前台通知，期间其他工具可用 |
| 模型复用与完整性 | 固定资源大小/SHA-256，有限扫描既有位置；外部完整模型可只读引用 | 固定资源大小/SHA-256，受管目录间直接复用；导入自定义模型校验结构与记录指纹 |
| 运行环境与存储 | EXE 首次准备私有环境；默认有空间的数据盘 AI-Models，可自选目录 | CPU 扩散/ONNX 环境随 APK 提供；模型位于有空间的应用 AI-Models，可选应用存储卷 |
| 路径与目录 | 显示实际模型及环境路径，Explorer 打开对应目录 | 显示实际模型及目录；应用内列出文件/大小/分片并可复制路径 |
| 删除与清理 | 确认后删选中受管模型或清理受管 AI 环境/模型；保护外部引用 | 确认后删受管模型/分片/任务缓存；APK 内置运行库通过卸载应用移除 |

手机没有 Windows 的 D/E/F 盘符，也不能安装 Windows Python/CUDA。两端使用同用途的配套模型、进度与提示词功能，运行库、可导入格式、文件权限及性能策略按平台适配；没有承诺输出像素相同。SDXL 手机端仍是实验备用，不能凭桌面结果宣称手机已验证。

## 手机运行条件与验证边界

普通工具支持 Android 5+，32 位 ABI 仅提供普通工具兼容；本轮尚无完成的 32 位设备回归。离线 AI 需要 Android 7+ 的 64 位系统。软件读取实际运行内存、当前可用内存及 CPU，不以“2024 年以后发布”作为通过条件。

自动策略在总内存不足 10 GiB 时选 384 像素工作分辨率（可手选 320），否则选 512 像素，默认至多四个 CPU 线程；生成前 SD 1.5 要求至少 3 GiB 可用系统内存，SDXL 要求 9 GiB。其他应用、系统限制与模型差异仍可能导致失败，CPU 生成耗时需以手机实测为准。

当前 384 像素圆点流程已完成新的复杂图离线原生生成：完整图及缩图经两套库扫码通过，手动位置和完整画布保留，约 12 分 50 秒，期间页面可操作。已去掉方形白底；圆点仍可见，自然度没有达到参考图。普通工具核心及界面重新回归、正式 APK 实际安装导航通过。ARM64 真机、手机 SDXL 和压缩传输未验证；详见 [最新验证记录](VALIDATION.md)。

## 三端图片混淆

Windows、Android 和单文件网页统一 Gilbert 默认系数 1.0、混淆与解混淆各一次、无损 PNG、原尺寸、颜色调整关闭。支持分别输入 1–20 次、手动还原、次数候选预览确认、任意批量子集和取消。混淆页面去掉其他算法、源文件附件、参数记录与压缩模拟；其他工具原有文件封装和检查功能保持独立。网页提供三列操作、ZIP 和中英切换。不同平台编码器可能产生不同文件字节，Canvas 透明颜色取整遵循浏览器行为。真机限制见验证记录。

## 封面混淆试用

Windows 与 Android 的双图切换、文件伪装均提供默认关闭的封面像素混淆。文字和编号在混淆后绘制，原有还原方式保留。独立网页只处理普通混淆，不封装 APNG 或文件附件。平台通过率与真机仍需实测。


## 1.2.4 参数识别与视频清信息

三端统一搜索系数 0–2（步进 0.1）和次数 1–20，分组相同置换，展示前三个预览，由用户确认。不能保证唯一推断参数。EXE/APK 新增独立视频板块；支持 MP4/MOV/M4V、WebM/MKV 容器信息清理，保留编码音视频、旋转与时长。网页仍专注图片混淆。
