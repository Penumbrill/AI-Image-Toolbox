# 图片混淆算法与使用

默认 Gilbert，移位系数 1.0，混淆与解混淆各 1 次，无损 PNG、原尺寸，颜色调整关闭。导入后点击“生成混淆图”即可。

混淆和解混淆分别设置整数次数 1–20。每次沿同一曲线路径移动相同的整数偏移；多次处理不等于直接乘大移位系数。程序在内存完成全部次数，然后编码一次，避免重复 JPG 编码损伤。还原必须匹配尺寸、系数、次数。

次数候选尝试 1–20 次，按像素邻接差异排序，展示三个预览并由用户确认。没有参数记录时无法唯一推断次数；周期置换、单色图、未知系数、缩放、颜色调整均会使候选不可靠。候选只更新还原次数，不自动导出。

PNG 输出不附带源文件或私有参数。JPG 默认质量 95，有损，透明处使用黑底。增强绿色在每次混淆前执行，减弱绿色在每次解混淆后执行；限幅不可逆，均默认关闭。网页使用 Canvas 解码和编码，透明颜色可能取整，原始文件字节不作为还原目标。

客户端内部保留旧版算法及文件格式读取用于兼容与回归，不在当前混淆界面提供旧模式，也不在新输出中加入附件。文件伪装等其他页面不受本次精简影响。

Bilibili 保存图片需先加载“查看原图”，再保存。此次 1280×1920 与 1206×1809 为相同比例，用户已确认保存的是缩放预览；服务器原图仍为 1280×1920。平台审核通过率未进行发布实测，不声称 100% 通过。
