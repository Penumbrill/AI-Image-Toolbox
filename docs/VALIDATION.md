# 验证范围

[English](VALIDATION.en.md) | [返回首页](../README.md) | [安装包与更新说明](RELEASES.md)

更新日期：2026-10-12。以下记录当前正式 EXE / APK 的已完成检查及限制。源码中具备功能，不等于所有设备、图片和模型均已通过验证。

## Windows

- Windows 生产界面完成 11 个页面的核心与完整双语回归，覆盖实际控件交互、切换语言后参数保留、批量导出/还原、打码会话、二维码导入导出与联动，以及文字图层和预览定位。
- 自动提示词开关在手动放置时保持可见，关闭后允许编辑；两个定位选项最多选择一个，也可都关闭。空预览选图、清空预览、模型与参数入口完成界面回归。
- 数值框滚轮、原色强度与恢复自动、透明 PNG 和背景显图的像素及解码回归通过。C# / JVM 使用共同向量比较颜色处理结果。
- Media Foundation 相机采集在 ASUS FHD webcam 实际开启两次，每次取得 4 帧 640×480 图像，关闭后可重新开启。未据此验证其他相机、红外设备或所有光学扫码场景。
- 默认 SD 1.5 的桌面融合链已有实际生成及扫码验证。SDXL 测试没有建立同等稳定性，因此保留实验备用标识；自定义模型不能据此保证效果。

## Android 普通工具与界面

- API 35 x86_64 模拟器完成普通工具核心与完整界面回归，包括空预览导入、任意非相邻队列子集、批量处理、RGBA / HEX 颜色、保持源比例的文件封面，以及打码撤销与完整画布。
- GIF 逐帧播放、停止、循环与非循环结束，WebUI / ComfyUI 参数读取与全部复制、64 位 seed，以及编号、尺寸、GIF 默认值持久化通过。
- 实际保存与分享产物的字节比较通过；输出相册和授权目录入口使用真实系统 Intent。QQ 往返报告会比较两份封装文件，但本机比较不能代替 QQ 实际压缩或传输测试。
- 自动提示词与定位独立、两个位置选项最多一个或都关闭、自动避让时隐藏定位示意、清空预览、模型方案切换与参数保存完成回归。44 次页面切换中位数为 33 ms，95 分位为 35 ms。
- 正式 APK 已实际安装和触摸检查二维码、模型方案与已下载文件清单、设置及教程；安装包字节与公开 APK 完全一致。测试类未进入正式包。

## 二维码与模型管理

- 真实 QQ 彩色圆环点阵截图与微信带图标截图各为 1206×2622。生产导入各识别一个二维码，按原始内容重新生成 512 像素标准码后再次解码内容一致，源截图不变。账号内容、原截图和私有路径未纳入公开文件。
- 生产 Android 模型管理器在真实本地 HTTPS 服务完成 16 组主机回归：证书与禁止 HTTP 降级、续传与重启、错误范围与截断、错误哈希、取消、尾部篡改、原位置复用、重复导入、完成门限和受管删除保护。
- 资源未全部校验时整体进度最多为 99%，只有所有必需资源就绪才报告完成。目录 junction 越界拒绝通过；文件 symlink 因主机权限未能建立，未完成该项测试。上述主机检查不代表手机镜像下载速度或多物理存储卷切换已实测。

## Android 真正离线 AI

- `AiVision` 使用固定版本的真实 BLIP、SegFormer 与动漫人脸 ONNX 权重，未以肤色阈值代替模型。三张复杂图的主机识图与九组提示词比较通过；Android 模拟器处理同一 1920×1280 图的四组保护/材质数组与主机输出逐字节一致。
- arm64-v8a 与 x86_64 原生扩散库均完成真实构建；x86_64 模拟器实际加载固定库，完成生命周期检查、128×128 一步 ControlNet 扩散，以及编码阶段取消。小尺寸用例不作为完整融合质量证明。
- 最终完整生产运行在 API 35 x86_64、8 GiB 模拟器中关闭 Wi-Fi / 蜂窝并开启飞行模式，真实执行识图、材质分区、人脸保护和 DreamShaper 8 / QR Monster SD 1.5 扩散。
- 本次工作尺寸 384、24 步设定、CFG 5.5、重绘 0.42、ControlNet 0.8；手动横向 20%、纵向 75%、大小 38%。输出为完整 1920×1280，所选区域 x=159、y=735、边长 451 未自动移动；区域外每个像素及 486,477 个保护像素保留。
- 首个原生候选完整图直接解码失败，直接缩图检查因短路未执行。经圆点局部亮度校准后，Android ZXing 与独立 ZXing-C++ 均在完整图及 900×600 缩图上核对相同内容通过。总耗时 770,402 ms，约 12 分 50 秒；期间可切换设置与二维码页面，任务继续运行。
- 实际观察结果保留蓝色建筑和棕粉树木，没有方形白色/模糊底板，但圆点与部分浅色分隔仍可见，自然度尚未达到所有参考图。此结论仅覆盖这一张图和这一处手动位置。
